What you'll build

One approach, applied to a real problem

The opening expert-led session introduces the first steps of building an AI agentic solution, including what an agent is, best practices, Skills, MCPs, and how the pieces fit together. Your team then applies these foundations to a small, practical problem.

Illustrative examples

What an assigned problem could look like

After the opening session, you will meet your assigned team and receive a problem statement. Your team will then have three hours to ideate, divide the work, and implement an AI Agent.

📝

Refinement Agent

Turns rough tickets into well-formed stories with acceptance criteria.

in: "login is slow sometimes"
out: story + acceptance criteria + open questions

Skills it might use

  • Story-writing template
  • Acceptance-criteria checklist

MCP tools it might connect

  • Jira: read and update tickets
  • Confluence: product context

Stretch goal: flag tickets that are too big and suggest how to split them.

✅

Test Case Creation Agent

Writes structured test cases from a user story or spec.

in: user story or spec
out: positive, negative and edge cases

Skills it might use

  • Test-case format
  • Edge-case heuristics

MCP tools it might connect

  • Jira: read stories
  • Test management tool or a spreadsheet

Stretch goal: turn the cases into automated test skeletons.

🐞

Bug Analysis Agent

Triages bug reports and suggests likely root causes and next steps.

in: bug report + logs
out: severity, likely cause, next step

Skills it might use

  • Triage rubric
  • Log-reading guide

MCP tools it might connect

  • Jira: read bugs
  • GitHub: search recent changes

Stretch goal: find duplicate bugs and link them.

These examples illustrate the scope and format of the challenges. The actual problem statement will be assigned to each team on the day.
