Refinement Agent

Turns rough tickets into well-formed stories with acceptance criteria.

in: "login is slow sometimes"
out: story + acceptance criteria + open questions

Skills it might use

  • Story-writing template
  • Acceptance-criteria checklist

MCP tools it might connect

  • Jira: read and update tickets
  • Confluence: product context

Stretch goal: flag tickets that are too big and suggest how to split them.

I want to build this →
✅

Test Case Creation Agent

Writes structured test cases from a user story or spec.

in: user story or spec
out: positive, negative and edge cases

Skills it might use

  • Test-case format
  • Edge-case heuristics

MCP tools it might connect

  • Jira: read stories
  • Test management tool or a spreadsheet

Stretch goal: turn the cases into automated test skeletons.

I want to build this →
🐞

Bug Analysis Agent

Triages bug reports and suggests likely root causes and next steps.

in: bug report + logs
out: severity, likely cause, next step

Skills it might use

  • Triage rubric
  • Log-reading guide

MCP tools it might connect

  • Jira: read bugs
  • GitHub: search recent changes

Stretch goal: find duplicate bugs and link them.
